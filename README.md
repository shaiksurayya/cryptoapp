# Cryptoverse

Cryptoverse is a cryptocurrency dashboard built with React that displays real-time crypto data and news.

## Features
- View top cryptocurrencies
- Check crypto prices and market stats
- Latest cryptocurrency news
- Responsive UI

## Tech Stack
- React
- Redux Toolkit
- Ant Design
- Crypto APIs
